# منصة المراجعة الداخلية والرقابة بالسجون

نسخة مطورة مبنية على مشروع `audit_platform_integrated_latest` مع تضمين التعديلات الرئيسة التالية:

- فصل دور **مختص الإدارة الرئيسية** عن **مدير إدارة المراجعة الداخلية**
- دعم الإسناد من **الجهاز الرئيسي** أو **المنطقة** أو **إسناد مختلط**
- تحسين الواجهة إلى **Side Menu يمين** وهوية حكومية أكثر وضوحًا
- إضافة شعاريّْن بصيغة SVG كعناصر واجهة قابلة للاستبدال بملفاتكم الرسمية
- توسيع الداشبوردات ورسومات KPI/KRI لكل دور
- دعم سجلات تتبع **Audit Log** وعرضها داخل صفحة المهمة
- تحسين نماذج التنفيذ والملاحظات والحقول الشرطية
- تحديث بيانات seed لتكون أقرب للواقع التشغيلي

## التشغيل

```bash
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
python run.py
```

ثم افتح:

```text
http://127.0.0.1:5000/login
```

## ملاحظة

تم التحقق من **سلامة صياغة Python بالـ compile** داخل بيئة التسليم، لكن لم يتم تشغيل Flask فعليًا هنا لأن مكتبات Flask غير مثبتة في البيئة الحالية.


أكيد، هذه قائمة الحسابات الموجودة في ملف الـ `seed.py` الذي أعطيتك، مع **اسم المستخدم + الاسم الظاهر + المسمى + الصلاحية/الدور**.

## صلاحياتهم

### `central_admin` و `central_operator`

صلاحيات تشغيلية مركزية:

* إنشاء المهام.
* تحديد المناطق.
* تحديد السجون مبدئيًا أو تركها للمنطقة.
* متابعة تقارير المناطق.
* مراجعة الملاحظات.
* فتح مسار التلافي والمعالجة.
* إعداد التقرير الأولي والنهائي.
* إدارة النماذج والخطة السنوية.
* الاطلاع على المؤشرات والسجلات.

### `central_director`

صلاحيات قيادية داخل إدارة المراجعة:

* الاطلاع الكامل.
* مراجعة التقرير الأولي.
* اعتماد التقرير النهائي.
* التوجيه أو الإرجاع للمختصين.
* إرسال التقرير للمدير العام.
* اعتماد الإغلاق النهائي.

### `dg`

صلاحيات المدير العام:

* رؤية لوحة قيادية عليا.
* رؤية التقارير النهائية فقط.
* اعتماد التقرير أو إصدار توجيه.
* إغلاق التقرير النهائي.
* لا يرى تنفيذ الجولات اليومية ولا يعدل التقارير التشغيلية.
